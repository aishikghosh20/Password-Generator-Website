# 🔐 Password Generator Website

A sleek, modern password generator built using **HTML, CSS, and JavaScript**. Generate secure random passwords with customizable options through a responsive glassmorphism-inspired interface.

---

## ✨ Features

- 🔢 Adjustable password length (1–32 characters)
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include special symbols
- 📋 One-click copy to clipboard
- 🎥 Animated looping video background
- 💎 Glass-morphism UI with neon hover effects
- 📱 Fully responsive design for desktop and mobile

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## ⚙️ How It Works

1. Choose the desired password length.
2. Select one or more character types.
3. Click **Generate**.
4. Copy the generated password using the **Copy** button.

Passwords are generated randomly using JavaScript's `Math.random()` function from the selected character pools.

## 🎨 Customization

### Change the Favicon

Replace

```
favicon.ico
```

with your own icon and update the `<head>` if necessary:

```html
<link rel="icon" href="favicon.ico" type="image/x-icon">
```

For PNG icons:

```html
<link rel="icon" href="favicon.png" type="image/png">
```

---

### Change the Background Video

Replace

```
bg-video.mp4
```

with your own video and update the HTML if the filename changes.

Example:

```html
<video autoplay muted loop id="bg-video">
    <source src="bg-video.mp4" type="video/mp4">
</video>
```

> For the best visual quality, use a dark looping MP4 video with a resolution of 1080p or higher.
